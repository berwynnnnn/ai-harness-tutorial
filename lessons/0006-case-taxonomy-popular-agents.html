LLM Agent 与 Harness 工程 · 案例课 06（智慧阶段）

分类学解剖：ChatGPT / Codex / Claude / Claude Code / Cursor / WorkBuddy / Manus

七个热门产品，行业命名一团乱。本课用四课框架给它们"正名"：三类物种、三种编程形态、一条透明度光谱。

前置知识：案例课 05

1. 三类物种

类别产品定义
聊天助手 + Agent 能力（超级应用） ChatGPT、Claude 本体是对话；Agent 模式（浏览器操控、深度研究）是附加能力
垂直编程 Harness（三形态） Cursor、Claude Code、Codex 同一 Agent 内核，分别装在 IDE / 终端 / 云端三种壳里
横向交付平台（通用/办公 Agent） Manus、WorkBuddy 一句话委托、异步交付成果，"AI 同事"定位

严格说 ChatGPT/Claude 的主体不是纯 Agent 产品，而是"长了 Agent 手臂的聊天助手"。

2. 编程三兄弟：同一内核，三种自主度档位

CursorClaude CodeCodex
形态AI 原生 IDE（VS Code 分支）终端命令行 Agent云端 Agent + CLI + IDE 插件
交互模式结对编程：Tab 补全 + Agent 模式委托任务，全程可介入、权限关卡派活：云端并行，产出 PR 供审阅
循环透明度最高（每次改动可见可确认）高（暴露工具调用与确认）低（审最终 PR，不审过程）

三者抢的是同一条光谱上的不同位置：深度参与 ↔ 彻底甩手。谁对取决于任务类型与用户信任度，不是技术强弱。Codex 官方还发过一篇《Unrolling the Codex agent loop》，是第 02 课的最佳延伸阅读。

3. 横向交付平台：Manus 与 WorkBuddy

ManusWorkBuddy（腾讯云代码助手团队）
定位通用自主 Agent 先行者（2025-03 爆红）"一人指挥，全行业专家执行"的办公工作台
执行方式云端虚拟机自主执行，异步交付多 Agent 并行、20+ 技能包、桌面/IM/小程序多端
护城河通用任务的自主规划腾讯生态 + 企业版（管理后台/数字员工）

与千问办公同物种：隐藏循环、只给交付物、技能沉淀复用。评估难度全场最高。

4. 三条横切洞察

  1. 透明度光谱：Cursor（全透明）→ Claude Code → Codex 云端 → ChatGPT/Claude → Manus/WorkBuddy（全隐藏）。规律：用户越专业、任务风险越大，循环越暴露。
  2. 技能生态成为共同战场：Claude Code Skills、WorkBuddy 开放技能生态兼容、Manus 任务模板、Qoder Skills——"把成功经验固化为可复用资产"已是平台标配，生态比模型难抄。
  3. 评估难度排序进化速度：编程三兄弟（测试=免费评分器）> 超级应用 > 横向交付平台（评估靠人工堆）。
