Agent Loop 速查卡

压缩自第 02 课。日常查阅用，可打印。

核心公式

Agent Loop = while(未完成) { 模型决策 → Harness 执行工具 → 结果回填上下文 }
模型 = 只输出意图（文字）；Harness = 唯一执行者

一轮循环 7 步

#步骤执行者
1组装上下文（提示词+工具清单+历史）Harness
2推理决策（调工具 or 直接回答）模型
3解析输出Harness
4权限/安全关卡Harness
5执行工具Harness
6结果回填（观察）Harness
7终止检查，否则回到 1Harness

数据流速记

  • 模型输出 tool_use {name, input} → Harness 校验+执行 → tool_result 回填历史 → 再次调用模型
  • 每轮重发全部历史 ⇒ 上下文单调增长 ⇒ 成本↑、旧信息持续影响模型
  • 工具描述 = 提示词的一部分，决定模型用得对不对

终止条件

类型触发方机制
正常完成模型输出最终回答，stop_reason=end_turn
保底刹车Harness最大轮数 / 费用预算 / 超时 / 错误熔断
外部干预用户中断、修改指令

注意：end_turn ≠ 任务真完成；严肃产品需加结果校验。

失败模式 → 对策

模式对策
死循环轮数上限 + 重复调用检测注入提醒
幻觉工具/参数清晰的工具描述 + 校验失败时回传原因供重试
目标漂移目标固定在系统提示词；长任务拆短循环
上下文爆炸压缩/摘要、按需检索（→ 上下文工程）
错误信息反噬为模型重写报错：讲清现状+建议下一步

PM 指标

平均循环轮数 · 任务完成率 vs 模型自认完成率 · 单任务成本 · 用户中断率
